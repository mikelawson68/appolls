# Contributing to apPolls

Report a reproducible issue with WordPress, PHP, and plugin versions, the steps to reproduce, expected behavior, and actual behavior. Reproduce on a test site and redact personal information.

Keep pull requests focused. Describe the user-visible change and how you verified it. Preserve standalone functionality, existing data, consent records, and compatibility with WordPress 6.4 and PHP 8.0. Do not add a required hosted account or paid functionality gate to the community distribution.

Contributions must be compatible with GPLv2 or later. Identify third-party dependencies and retain their license notices. Never commit credentials or customer data. Report suspected security issues using SECURITY.md rather than a public issue.

# Security reports

Report suspected vulnerabilities privately to support@artistprowp.com with "Security report" in the subject. Include the affected version, a minimal reproduction using synthetic data, likely impact, and a contact address. Do not include customer exports, passwords, full license keys, or payment details.

Please avoid publishing exploit details in a public issue before the maintainer has assessed the report. No guaranteed response time or bug bounty is offered. Back up production sites and apply published security updates promptly.

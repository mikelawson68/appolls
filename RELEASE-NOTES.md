# apPolls 1.0.2

Community release under GPLv2 or later. Standalone plugin functionality is included without paid activation or a private update client.

## Install

Download `appolls-1.0.2-community.zip` from this release. In WordPress, use Plugins → Add New → Upload Plugin, install the ZIP and activate apPolls. A license key is not required for this community build.

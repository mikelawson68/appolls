# apPolls

[**Buy one year of updates and support — $39, one site**](https://artistprowp.com/checkout/?product=appolls&plan=annual&sites=1) · [All plans](https://artistprowp.com/appolls/) · [Get help](https://artistprowp.com/support/)

WordPress polls with live results and first-party response data.

- Six question types
- Scheduled voting and configurable result visibility
- Response controls and CSV exports

## Requirements

WordPress 6.4 or later; PHP 8.0 or later. Tested on WordPress 6.4 and 7.1.3 with PHP 8.3. The production retail deployment uses PHP 8.4.

## Installation

Use a packaged release ZIP, not GitHub's source-code ZIP. In WordPress, choose Plugins → Add New → Upload Plugin, upload the release ZIP, then activate apPolls. Community users can skip the license-activation step in the guide. See the [getting-started guide](https://artistprowp.com/docs/appolls-getting-started/).

The community distribution does not require a license key and does not contact a private licensing or update service. The retail distribution includes the commercial update client; activate its service key under apPolls → License.

Create unlimited, accessible WordPress polls with live results, scheduling, duplicate-response controls, CSV exports, and data ownership.

== Description ==

apPolls gives publishers, businesses, schools, nonprofits, and membership sites a fast poll builder inside WordPress. No hosted poll account is required and response data stays in your WordPress database.

Features include:

* Unlimited polls and responses
* Single choice, multiple choice, yes/no, 1–5 rating, agreement scale, and open text questions
* Start and end scheduling
* Configurable results visibility
* Accessible, responsive frontend design
* Visitor and email duplicate-response classification
* Live percentage results
* CSV response export
* Optional profile-routing and AI workflow foundation
* Free plugin functionality with optional paid implementation and support

== Installation ==

1. In WordPress, go to Plugins > Add New > Upload Plugin.
2. Upload the apPolls ZIP and activate it.
3. No license key is required for plugin functionality.
4. Open apPolls > Add New, create a poll, and add questions.
5. Set the poll to Active and paste its shortcode into a page or post.

== Frequently Asked Questions ==

= Does apPolls require another artistproWP plugin? =

No. apPolls is a standalone WordPress plugin. Its integrations are optional.

= Where is response data stored? =

In dedicated tables in your own WordPress database.

= Does deactivation remove my polls? =

No. Deactivation and uninstall do not erase poll or response data.

== Paid support ==

Optional implementation and support are available at https://artistprowp.com/support/. Purchasing support is not required to use the plugin. No license server or private update service is contacted by this directory build.

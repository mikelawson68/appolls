# Launch preparation

Retail version 1.0.2 contains the tested launch hardening. Mike confirmed the plugins were built as open source; GPLv2-or-later metadata has been aligned with that intent. Paid plans cover services, not restrictions on GPL usage.

This repository remains private pending public-release preparation. The community-candidate branch removes the private updater and paid activation. Remaining gates include WordPress.org maintainer identity, warning triage and manual review.

GitLab is the working authority. GitHub mirrors reviewed commits. Neither remote deploys to production automatically.
